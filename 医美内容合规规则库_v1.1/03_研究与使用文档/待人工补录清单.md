- **目标文件均位于** `医美内容合规规则库_v1.1/` 下

- 证据实体文件（PDF/HTML/截图）存放到 `04_来源证据/` 对应编号子目录，并回填该目录下的 `*_metadata.json`

- 不确定的信息保持 `pending_verification`，禁止伪造文件、哈希或文号

### 补什么

各案的**处罚决定书文号**（如「京市监处罚〔2021〕XX号」），可在 [信用中国](https://www.creditchina.gov.cn) 或 [国家企业信用信息公示系统](https://www.gsxt.gov.cn) 按当事人企业名称查询行政处罚记录获取。

### 补到哪里

- 文号 → `02_系统调用数据/enforcement_cases.json` 对应案例的 `decision_number` 字段
- 同时把该案 `verification_status` 由 `partially_verified` 改为 `verified`
- 如下载了决定书文件 → 存 `04_来源证据/05_处罚案例/官方案例/`，回填对应 `C00xx_metadata.json`

## 七、补录后的操作规范

1. 修改 JSON 后运行乱码检查：
   ```
   python -c "import re,glob;[print(f,len(re.findall(r'\ufffd',open(f,encoding='utf-8').read()))) for f in glob.glob('02_系统调用数据/*.json')]"
   ```
2. 每批补录在 `changelog.json` 末尾追加一条记录（change_id 顺延，changed_by 填补录人）
3. CSV 与 JSON 的同步可以交给我批量重生成，无需手工编辑 CSV
