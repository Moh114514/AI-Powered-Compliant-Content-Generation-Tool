# 小红书违禁词库（xhs_banned_words.json）

> 用途：小红书违禁词检测 AI 工具的底层词库输入。
> 版本：v1.0（公开可溯源资料汇编，非官方全量库）
> 生成日期：2026-07-29

## 一、文件说明
- `xhs_banned_words.json`：主词库，纯数组，每条一个违禁/敏感词对象。
- `_part1_医美医疗.py` / `_part2_引流极限词.py` / `_part3_功效承诺.py`：原始数据模块，便于维护。
- `build.py`：构建脚本，合并模块 → 生成 JSON，并做去重 + 字段完整性 + U+FFFD 校验。

修改词库：编辑对应 `_part*.py` 后运行 `python build.py` 即可重新生成。

## 二、单条结构（增强版）
```json
{
  "id": "BW0001",
  "word": "超声刀",
  "domain": "医美",
  "risk_level": "违禁",
  "replacement": "射频紧致类项目（需机构资质，禁止无资质宣传）",
  "reason": "医美器械名称，平台严管无资质宣传",
  "variants": ["超生刀", "超声🔪", "超声波刀"],
  "source": "小红书医美治理专项公告(S-XHS-01/02/03)"
}
```

| 字段 | 含义 |
|---|---|
| id | 稳定唯一编号 BW0001 起 |
| word | 原词（主匹配词） |
| domain | 领域：医美 / 医疗 / 引流 / 极限词 / 功效承诺 |
| risk_level | 风险等级：违禁 / 敏感 / 限流 |
| replacement | 合规改写建议（检测命中后的替换/删除指引） |
| reason | 违规原因简述 |
| variants | 变体写法（谐音、拆分、符号替代、拼音缩写等），检测时须一并匹配 |
| source | 来源说明（可追溯） |

## 三、领域与风险分布（v1.0）
- 医美：54 条
- 医疗：25 条
- 引流：40 条
- 极限词：18 条
- 功效承诺：37 条
- 合计：174 条（其中 违禁 140 / 敏感 34）

> 说明：`risk_level` 仅取「违禁 / 敏感」两级（本期无触发“限流”单独等级的词；限流多为叠加处罚结果）。如需“限流”维度可在后续版本补充。

## 四、检测工具接入建议
1. 匹配集合 = `word` + 所有 `variants`（变体是规避审核的高频手段，必须覆盖）。
2. 命中后按 `risk_level` 分级处置：违禁→阻断/强提醒；敏感→软提醒并给 `replacement` 建议。
3. 注意**上下文判定**：部分词在个人体验语境下可合规（如“用了感觉皮肤变亮了”vs“美白效果超好”），建议结合句式模型而非纯词匹配。
4. `source` 用于可信度标记与人工复核追溯。

## 六、局限性
