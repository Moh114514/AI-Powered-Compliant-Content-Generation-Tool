AI 医美内容合规工作台（Windows 便携版）

使用方法

1. 双击 AI_Compliance_Workbench.exe。
2. 等待启动窗口显示“运行中”，浏览器会自动打开工作台。
3. 使用结束后，在启动窗口点击“退出程序”。

注意事项

- 无需安装 Python 或 Node.js。
- 程序只监听本机 127.0.0.1，不会作为公网服务运行。
- 设置、提示词配置和历史记录保存在：
  %LOCALAPPDATA%\AIComplianceWorkbench
- 当前内部版已内置构建时的 .env，并默认使用其中的真实模型配置。
- 首次启动会把内置配置写入“配置目录”的 .env；后续手工修改的 .env 不会被升级包覆盖。
- 每次启动都会强制使用 .env 中的 Provider、模型、Base URL、温度和 Token，旧版 SQLite 模型设置不会覆盖。
- API Key 不会显示或保存到网页设置中。如需更换 Key，请点击启动窗口的“配置目录”并编辑 .env。
- 如果本地服务启动失败，程序会自动生成诊断日志：%TEMP%\AI_Compliance_Workbench_startup_error.log。
- 本工具只用于内容风险筛查，不替代正式法务或医疗专业意见。
- 部分安全软件可能会对未签名的单文件 EXE 提示风险；请从可信渠道下载并核验文件 SHA-256。
