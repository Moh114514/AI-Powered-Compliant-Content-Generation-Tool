# 已知限制

- 规则库中的法律结论仍需法务或合规负责人复核；
- 文本检测不能替代图片、视频、病例、证件和授权文件审查；
- MockProvider 仅用于演示，不代表真实模型能力；
- 外部模型输出存在不确定性，解析失败时系统只会降级为人工复核；
- 回归测试通过率用于版本比较，不等同于真实业务准确率；
- v1.2 Mock 基线当前为 206/320（64.38%）；正常合规样本通过率 94%，剩余缺口主要集中在隐含语义、对抗表达及核心规则 ID 映射；
- 56 条 `pending_review` 规则尚待法务或合规负责人确认，命中时系统会强制人工复核；
- 当前工具不含账号、审批、组织权限、自动发布或平台接口集成；
- 平台规则会变化，需要定期更新来源、平台映射和测试样本。
- 2026-07-28 的 npm 安装报告提示 3 个中等和 1 个高风险依赖公告；当前环境未授权向外部审计服务发送完整依赖元数据，需由维护者在可信网络中复核。
