## 目标

完善医美内容合规工作台的检测可靠性、降级策略、前端可用性和工程验收能力。

## 主要变更

- 修复 L1/L4 复核优先级与重叠规则命中丢失；
- 让语义风险参与总体聚合，模型失败时强制人工复核；
- 加强 JSON 引用、正则、来源与状态校验；
- 改写稿自动复检，避免重复模型调用；
- 修复品牌禁用词注入错误；
- 增加规则回归测试 API 和设置页入口；
- 强化 SQLite、请求超时、输入校验和 CORS；
- 改善生成、检测、规则查询页面；
- 增加 pytest、前端构建 CI、启动脚本和文档。

## 验收

- `python -m pytest -q`
- `npm run build`
- 网页设置页运行数据校验与规则回归测试

## 注意

本 PR 不修改正式规则 JSON；本地 v1.2 规则库需要另行同步到 `data/compliance`。
